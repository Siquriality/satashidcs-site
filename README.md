# SatashiDCS Site

Одностраничный концепт сайта SatashiDCS. Репозиторий содержит самостоятельную HTML-страницу с оформлением и интерактивными элементами для просмотра идеи интерфейса.

## Запуск

Откройте `index.html` в браузере. Сервер и установка зависимостей не требуются.

## Состав

- `index.html` — разметка, стили и поведение страницы.

Это демонстрационный макет. Перед использованием как рабочего сайта проверьте тексты, ссылки, доступность и подключение реальных сервисов. Лицензия на повторное использование не указана.
